# Campaign Planning Documents

This directory is reserved for the working planning documents that defined the
Sprint 2 and Sprint 3 decision criteria before their corresponding experiments
were run.

These files are not a public pre-registration record, and the manuscript does
not claim formal registration. They are internal working documents from the
computational campaign. The intended provenance is:

- H1--H4 were specified in the sprint planning material before the short-budget
  and scale experiments were executed.
- Q5 was specified before the final cold-MIP 10800-second scale runs were
  executed.
- The Git history does not by itself timestamp those planning documents because
  they were exchanged outside the repository during the campaign. In particular,
  the short-budget results entered the repository in commit `2d18a8b`
  (2026-07-06), the first 8X/10X results entered in commit `2bda4f8`
  (2026-07-08), and the manuscript text containing H1--H4 entered later in
  commit `c7e8837` (2026-07-08). This directory records that distinction
  explicitly so the supplemental package does not overstate the chronology.

The source planning files are pending author upload. When supplied, they should
be copied here verbatim.
